A preview of the tool: six test companies, with the real output of the analysis engine.

⚗︎ Invented companies, synthetic numbers. They are here to show how the tool reasons in the typical cases. These are not real companies and must not be used to decide anything. For real SET data, see the bottom of the page.

Trying it on real stocks

The analysis runs in Python and fetches the data on the spot, so from a phone it has to be put online once. That is free and takes a couple of minutes from the iPhone browser:

Open the pre-filled publishing form →
Sign in with GitHub, press Deploy, wait two minutes. You get an address of your own that you can add to the home screen.

Or, from a computer:

git clone -b claude/thailand-equity-analyzer-rfrfkp \
  https://github.com/giancarlo1963/stock-exchange.git
cd stock-exchange
pip install -r requirements.txt
streamlit run app.py

On the first stock you analyse, check the Data sources tab: it says which archive the payments came from and whether the other sources agree.

Automated processing of public data. This is not financial advice, nor a personalised recommendation. Always check the figures against the company's official statements and the Stock Exchange of Thailand website.
