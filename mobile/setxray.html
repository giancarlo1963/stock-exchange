Stock Exchange of Thailand

Trying it on real stocks

The analysis runs in Python and fetches the data on the spot, so from a phone it has to be put online once. That is free and takes a couple of minutes from the iPhone browser:

Open the pre-filled publishing form →
Sign in with GitHub, press Deploy, wait two minutes. You get an address of your own that you can add to the home screen.

Or, from a computer:

git clone -b claude/thailand-equity-analyzer-rfrfkp \
  https://github.com/giancarlo1963/stock-exchange.git
cd stock-exchange
pip install -r requirements.txt
streamlit run app.py

On the first stock you analyse, check the Data sources tab: it says which archive the payments came from and whether the other sources agree. The app itself has the same language switch as this page.

Automated processing of public data. This is not financial advice, nor a personalised recommendation. Always check the figures against the company's official statements and the Stock Exchange of Thailand website.

Provarlo sui titoli veri

L'analisi gira in Python e scarica i dati al momento, quindi dal telefono serve metterla online una volta sola. È gratuito e si fa dal browser dell'iPhone in un paio di minuti:

Apri il modulo di pubblicazione già compilato →
Entra con GitHub, premi Deploy, aspetta due minuti. Ottieni un indirizzo tuo che puoi aggiungere alla schermata Home.

Oppure, da un computer:

git clone -b claude/thailand-equity-analyzer-rfrfkp \
  https://github.com/giancarlo1963/stock-exchange.git
cd stock-exchange
pip install -r requirements.txt
streamlit run app.py

Il primo titolo che analizzi, controlla la scheda Fonti dei dati: dice da quale archivio arrivano gli stacchi e se le altre fonti concordano. Anche l'app ha lo stesso interruttore della lingua che c'e' in questa pagina.

Elaborazione automatica di dati pubblici. Non è consulenza finanziaria né una raccomandazione personalizzata. Verifica sempre i numeri sui bilanci ufficiali della società e sul sito della Stock Exchange of Thailand.
